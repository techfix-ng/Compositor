# Compositor for Windows

Native Windows port using .NET 8/WPF, a platform-neutral document model, a dedicated PSD/PSB importer, self-contained x64 publishing, and a conventional Inno Setup `Setup.exe` with uninstall support.

Run `./windows/build.ps1` on Windows with .NET 8 SDK and Inno Setup 6. The installer is written to `windows/artifacts`.

Milestones: 0.1 native shell/import/installer; 0.2 layered PSD; 0.3 editing tools; 0.4 GPU/color/performance/signing hardening.
